## addons

Folder `addons` berisi skrip JavaScript tambahan yang bisa diintegrasikan atau dipelajari sebagai contoh.

Isi saat ini:

- `RobloxSniffer.js` — skrip contoh/utility. Baca file untuk komentar penggunaan dan konfigurasi.

Cara pakai:

1. Pastikan `node` terpasang.
2. Jalankan skrip dari root `RobloxSniffer` atau gunakan `node` langsung:

```bash
node addons/RobloxSniffer.js
```

Catatan: Sesuaikan dependensi atau konfigurasi di dalam skrip jika diperlukan.
