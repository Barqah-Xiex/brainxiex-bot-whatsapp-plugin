## fitur

Folder `fitur` menyimpan fitur terpisah atau modul tambahan untuk repo. Struktur dapat berisi beberapa subfitur.

Contoh struktur:

- `Owner/` — fitur khusus owner, berisi skrip yang dijalankan untuk administrasi atau pengujian.

Panduan:

- Buka README di subfolder untuk instruksi spesifik (mis. `Owner/README.md`).
- Ikuti praktik keamanan: jalankan hanya skrip yang telah di-review.
