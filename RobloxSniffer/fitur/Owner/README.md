## Owner

Folder `Owner` berisi skrip khusus untuk penggunaan oleh pemilik proyek atau administrator.

Isi saat ini:

- `RobloxSniffer.js` — skrip yang mungkin menangani tugas admin atau testing. Buka file untuk keterangan lebih lanjut.

Cara pakai:

1. Pastikan Anda memahami fungsi skrip sebelum menjalankan.
2. Jika skrip menggunakan Node.js, jalankan `node RobloxSniffer.js` dari folder ini.

Catatan keamanan:

- Skrip dalam folder ini bisa berisi perintah yang sensitif; lindungi akses ke repository ini.
